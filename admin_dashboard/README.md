# SevakConnect Admin & Police Dashboard

The SevakConnect Admin & Police Operations Dashboard is built with Flutter and supports Flutter Web and cross-platform desktop/mobile.

## Location
- Source Code: [`../frontend/mobile/`](../frontend/mobile/)
- Entrypoint: [`../frontend/mobile/lib/main.dart`](../frontend/mobile/lib/main.dart)
- Web Runner: [`../frontend/mobile/web/`](../frontend/mobile/web/)

## Key Modules
- **Overview**: High-level real-time KPI metrics, active alerts, and quick actions.
- **Crowd Monitoring**: Crowd density reports and zone status along the Wari route.
- **Chandrabhaga River Zones**: River bank safety and restricted entry status.
- **Emergencies**: Incident dispatching and resolution tracking.
- **Lost & Found**: Missing persons / children case management.
- **Supplies**: Camp water, food, and medical stock monitoring.
- **Darshan Queue**: Temple Darshan batches and estimated wait times.
- **Volunteers**: Field volunteer tracking and assignment.
